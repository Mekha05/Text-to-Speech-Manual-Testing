# Text-to-Speech Web Application — Manual Testing

## Project Overview
This mini project focuses on manually testing a Text-to-Speech web application to verify its functionality, input handling, voice selection, and user interface behavior.

## Testing Activities
- Designed positive and negative test scenarios.
- Performed functional testing of text-to-speech conversion.
- Tested voice selection and text input behavior.
- Checked browser compatibility and responsive behavior.
- Documented defects and recorded test execution results.

## Testing Deliverables
- Manual test cases
- Bug report
- Test execution report

## Testing Types
- Functional Testing
- Positive and Negative Testing
- Browser Compatibility Testing
- Responsive Testing

## Tools Used
- Web Browser
- Microsoft Excel

## Project Files
- `Test-Cases-and-Bug-Report.xlsx` — Contains test cases, defect records, and execution documentation.

## Project Objective
To identify functional issues, validate expected application behavior, and document testing results systematically.
